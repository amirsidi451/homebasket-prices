HomeBasket 2.6.8

תיקונים ממוקדים: ניסוח מינימום אחיד, הודעות חיסכון באיסוף וסיור בדיקות מתוקן. אין שינוי בעיצוב האתר, בקונפיג או בחישובי עלויות.

  1. חלצו לתיקייה חדשה ושמרו את config.js המצורף.
  2. העתיקו את תיקיית data שלכם ליד index.html. נתונים אינם מצורפים ל-ZIP.
  3. הפעילו START_LOCAL.bat, או הגישו כאתר סטטי כפי שעשיתם בגרסה הקודמת.
  4. בדקו מינימום במצפה רמון וניסוח חיסכון בנתניה, חיפה והוד השרון. פירוט בקובץ התחילו כאן.
  5. גיבוי 2.6.7 נמצא בתיקיית backups.

תוצאות בדיקות אופליין מצורפות. בדיקות Playwright וטלפון אמיתי לא הורצו כאן.
