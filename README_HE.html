HomeBasket 2.5

עיצוב חדש, אותם חישובים ואותם נתונים. גיבוי 2.4 נמצא בתיקיית backups. האתר החי לא שונה.

איך פותחים?

  1. חלצו לתיקייה חדשה. שמרו את תיקיית 2.4.
  2. אם מילאתם config.js ב־2.4, אפשר להעתיק אותו בשלמותו לתיקייה החדשה. ההגדרות לא השתנו. למי שמשדרג מגרסה קודמת יותר: מדריך ההגדרות.
  3. סגרו את חלון ההפעלה הקודם, ולחצו פעמיים על START_LOCAL.bat בתיקייה החדשה. נדרש אותו Python שכבר מותקן אצלכם.
  4. טענו את אותה תיקיית נתונים דרך ״הנתונים שלנו״ אם אינה מחוברת. אין צורך לייצא בפורמט חדש.
פתיחת האתר

כך משתמשים

  1. עיר וקבלה: בחרו עיר ומשלוח או איסוף.
  2. בניית סל: חפשו, שנו כמות ולחצו הוספה. הסל נשאר בתחתית בטלפון ובצד במחשב.
  3. השוואה: לחצו ״השווה מחירים״. הרשת המובילה מופיעה בכרטיס גדול; רשתות 2 ו־3 בכרטיסים משניים.

השלבים נמצאים באותו עמוד. אפשר לגלול או ללחוץ על שלב למעלה. צילום קבלה, עריכת הסל ומסך הנתונים נשארו זמינים.

בגרף מופיעות כל הרשתות. סל חלקי או נתונים לא תקינים מקבלים הסבר — אין להם מחיר סל מלא מומצא. מידע מפורט נפתח בלחיצה. התשלום נעשה באתר הרשת.

מה כדאי לבדוק אצלכם?

  1. בנו סל מהנתונים האמיתיים ובדקו שחיפוש, כמויות והסרה פועלים.
  2. בדקו שהמוביל מציג את אותו סכום כמו ב־2.4 ושסלים מתחת למינימום אינם מובילים.
  3. פתחו וסגרו תחליף; אשרו חלופה רק אם רציתם.
  4. נסו רוחבים 360, 390, 768 ו־1280, ומצב כהה של המכשיר. ודאו שהכפתור התחתון זמין ושאפשר לגלול ברשימת הסל.
  5. נווטו עם Tab, Enter ו־Escape, כולל העלאת קבלה.

1,055 בדיקות אוטומטיות עברו. בדיקות הרוחב הן בדיקות CSS וחישובים; לא בוצעה בדיקה חזותית בדפדפן או בטלפון. הגופן מקומי ואין טעינת גופנים או ספריית עיצוב מאתר חיצוני.
