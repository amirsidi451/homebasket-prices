1. חלצו את כל ה-ZIP לתיקייה חדשה. השאירו את הגרסה הקודמת ללא שינוי.
2. שמרו את קובצי data שלכם בפורמט הקיים והעתיקו אותם לתיקיית data בחבילה.
3. שמרו בקונפיג את dataBase ואת serviceAreas האמיתיים שלכם. freeAbove הוא שדה רשות בשקלים, null כשאינו ידוע. בטיב טעם כבר הוגדר 750; אין לשנות ספים של רשתות אחרות בלי מידע.
4. הריצו START_LOCAL.bat כמו קודם; אין שינוי באתר החי.
5. לבדיקות אוטומטיות: python run_tests.py עם Node.js מותקן. תוצאות ההרצה מצורפות ב-test-results.txt.
6. לשמירה בביקור הבא סמנו את האפשרות הגלויה במסך העיר. המידע נשמר רק בדפדפן הזה. אחרי רענון לחצו על המשך סל שמור.
